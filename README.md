# Queens Of Change Foundation Website 

A modern and responsive NGO website developed using HTML, CSS, and JavaScript for the Queens Of Change Foundation Internship Selection Task.

## Project Overview

This project is designed to represent an NGO website that focuses on empowering women, supporting children, and uplifting communities through education, awareness programs, and social initiatives. 
The website includes modern UI features, responsive layouts, animations, dark mode, and interactive sections to provide a professional user experience.

## Features

- Responsive Navigation Bar
- Hero Section with Typing Animation
- About Section
- Impact Statistics with Animated Counters
- Image Slider / Gallery Carousel
- Donation Section
- Dark Mode Toggle
- Scroll Reveal Animations
- Responsive Design for Mobile Devices
- Professional Footer Section
- Smooth Scrolling Navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript

## UI Features

### Dark Mode
Users can switch between light mode and dark mode using the toggle button in the navigation bar.

### Typing Animation
Hero section text dynamically types different motivational statements.

### Animated Counters
Impact statistics animate smoothly when the page loads.

### Image Slider
Interactive image carousel with navigation buttons.

### Scroll Reveal
Sections smoothly appear while scrolling down the page.

## Responsive Design

The website is fully responsive and works on:

- Desktop
- Tablet
- Mobile Devices

## Purpose of the Project

This project was created as part of the internship selection process for Queens Of Change Foundation to demonstrate frontend development skills and UI design creativity.
